app/web 主题色说明

来源:docs/web.md §46,当前为 dark theme,light 主题仅占位未填。

主交互色

--accent · #00C487 · 主交互 / 品牌色(同时作 --success)
Tailwind:bg-accent / text-accent

背景层

变量值用途
--app#151515主背景(中 Conversation / 右 Extension / Setting)
--sidebar#252525左 Sidebar,比主背景亮 16 个灰阶
--panel#1C1C1C扩展区侧栏,只比主背景亮 7 阶
--surface#2B2B2B浮起表面
--surface-hover#303030hover
--surface-active#353535active

文字

变量值用途
--fg#E5E5E5主文字
--fg-bright#F5F5F5hover / active 高亮
--fg-2#C7C7C7次文字
--fg-3#A1A1A1三级文字
--fg-disabled#737373禁用

边框

变量值用途
--border#313131默认边框
--border-hover#3F3F3Fhover 边框

语义色

变量值用途
--success#00C487成功(同 accent)
--error#F05252错误
--warning#D9A441警告
--info#5B9CF6信息

切换主题:document.documentElement.dataset.theme = 'light' | 'dark',所有 token 通过 @theme inline 实时读取 CSS 变量,无需重建。
