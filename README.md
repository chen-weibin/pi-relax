# Relax

本地单用户的编程助手。一个进程里可以同时打开多个项目、多条会话；对话、工具调用和会话文件由 [pi coding-agent](https://github.com/badlogic/pi-mono) 负责。

## 能做什么

- **对话**：登记已有文件夹作为项目，也可以在默认工作区直接聊。多条会话可以同时打开、同时生成。回复是流式的，生成中可以排队续发，也可以中止当前这一轮。
- **模型**：按已配置的提供商列出可用模型，选择模型和思考档位。没有可用模型时不能开新对话。
- **工具**：读文件、搜索、改写、执行命令，以及网页搜索和抓取。技能按 pi 的默认目录加载。
- **工作区**：侧栏是项目和会话；中间是对话；右侧可以打开文件树、预览和编辑文本，也可以开终端。
